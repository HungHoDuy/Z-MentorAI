# Custom Rules & Behavioral Constraints

## Bug Reporting Constraint
- **Identify and Analyze First (QA Mode)**: Whenever a bug, error, or unexpected behavior is detected in the workspace, you must stop, investigate, and report the root cause/details to the user first. 
- **No Autodebugging**: Do not write any code modifications, fixes, or debug patches until you have explicitly presented the bug analysis to the user and they have approved you to proceed with debugging.
